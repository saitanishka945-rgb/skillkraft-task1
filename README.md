# Caesar Cipher - Encryption & Decryption

# Task 01

This project is developed as part of my **Cyber Security Internship**. It implements the **Caesar Cipher Algorithm** using Python to encrypt and decrypt messages based on a user-defined shift value.

# Objective

The objective of this task is to understand the basics of classical cryptography by implementing the Caesar Cipher algorithm, which encrypts and decrypts text using a fixed shift value.

#Features

- Encrypt plain text messages
- Decrypt encrypted messages
- Supports uppercase and lowercase letters
- Preserves spaces, numbers, and special characters
- Simple menu-driven interface
